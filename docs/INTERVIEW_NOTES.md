# Irene demo talking points

Updated 12 October 2026 to match the deployed release. See the [product status](PRODUCT_BUILD_PLAN.md) and [recorded verification](RELEASE_VERIFICATION.md).

- Start with the personal problem: needing therapy, finding it expensive, and struggling to ask for help without worrying family.
- Explain the solution: a private first step followed by an optional, therapist-approved circle that shares a session fee.
- Show fictional intake, consent and an editable Gemini summary. The live deployment uses real Google generation and embeddings; the offline local demo uses simulation.
- Show therapist review, constraint-based matching and reasons for suggestions. AI supports preparation; the therapist decides suitability.
- Demonstrate group approval, a fixed shared quote, participant acceptance, private preparation and calendar export. These features are implemented.
- Describe the deployed architecture: Firebase Hosting, Cloud Run, Gemini, Secret Manager and Supabase PostgreSQL. Cloud Build and Artifact Registry built and stored the backend image; Stitch informed the design.
- Use the recorded 30 backend tests, 6 frontend routing tests and 35 live workflow checks as software evidence. Do not present them as clinical or societal-impact measurements.
- Finish with the intended impact: lower cost barriers, dignity and control over disclosure, and professionally guided connection. Real-user validation is the next stage.

The [2:41 video](https://drive.google.com/file/d/1VxKqMv-1Tg9g7m6cUbuaK8eWOmsG7w3e/view) and prescribed-template deck are complete and published. No payment or real therapy session occurs in the demonstration.
