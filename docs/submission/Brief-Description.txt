Irene began with needing therapy in college, finding it expensive, and hesitating to tell parents because they would worry. We built a more affordable, less intimidating first step towards therapist-led support. People share concerns privately, review an AI-assisted summary, and choose a therapist-approved group with an upfront shared session fee. Peers cannot see each other's intake. Gemini drafts summaries, flags concerns for human review, supports matching through embeddings, and prepares facilitator briefs; therapists decide suitability. Firebase Hosting serves our React app, Cloud Run runs the Spring Boot backend, and Secret Manager protects credentials. Supabase PostgreSQL stores data; Firestore is not used. Cloud Build and Artifact Registry deliver the backend, while Google Stitch informed the coral UI. Aligned with Sustainability & Social Impact, Irene aims to reduce cost barriers while preserving dignity, choice and human care. The live prototype is tested with fictional data.
